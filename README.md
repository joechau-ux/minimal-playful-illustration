# Minimal Playful Illustration

A Codex Skill for generating minimal, playful, hand-drawn illustrations with stable visual DNA and controlled conceptual variation.

## Install

Copy the `minimal-playful-illustration` folder into your personal Codex skills directory, or ask Codex to install this folder as a personal Skill. Restart Codex if it does not appear immediately.

Keep the directory structure intact because `SKILL.md` uses relative links to the reference and asset inventory.

## Use

Examples:

```text
Use minimal-playful-illustration to turn this photo into an illustration.
Surprise: playful. Fidelity: feature-first. No text.
```

```text
Draw a cat drinking coffee in this style. Make it bold, but keep one clean idea.
```

If omitted, the defaults are `surprise: playful`, `fidelity: feature-first`, and no text.

- `SKILL.md` — activation description and core execution rules
