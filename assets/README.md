## Selection guide

Choose 2–4 Good Cases rather than attaching all eight:

- For bold contour and odd anatomy: `good-01`, `good-04`, `good-06`.
- For people meeting props or food: `good-02`, `good-08`.
- For small groups or paired characters: `good-03`, `good-07`, `good-08`.
- For sign-like restraint and negative space: `good-05`.
- For the most vivid, unruly energy: `good-06` plus `good-03` or `good-08`.

Never send a Bad Case to image generation as an unlabeled visual reference. Use Bad Cases only for diagnosis or explicitly label them as negative examples in text.
